# Org logos

Generated by [`scripts/build_logos.py`](../../scripts/build_logos.py). Do not
edit these files by hand — add an entry to `LOGOS` in that script and re-run it:

```sh
python3 scripts/build_logos.py     # regenerate
python3 scripts/verify_logos.py    # optional: check against a real renderer
```

## Embedding

Every mark shares one canvas height, so a single snippet works for all of them:

```html
<img src="assets/logos/<slug>.svg" height="24" align="middle" alt="">
```

`alt=""` is intentional: the heading text already names the org, so the image is
decorative and should not be announced twice by a screen reader.

## Why the files are vendored

The README previously hotlinked `https://www.google.com/s2/favicons?domain=...`.
That endpoint 301-redirects, is cached opaquely by GitHub's image proxy, and
returns whatever raster each site happens to ship (a mix of 32px, 48px and 64px
PNGs with arbitrary internal padding). Scaling that mix to one height gave every
logo a different optical weight and no shared baseline.

Vendoring fixes all three: the marks are local (no network dependency, no proxy
cache to go stale), vector (crisp at any size), and normalized by the build
script rather than by whatever each site shipped.

Three things get normalized:

**Vertical position.** Each mark is centered in a 24-unit band, with 3 units of
empty space below it. That padding offsets `vertical-align: middle`, which
otherwise centers on the x-height and sits low next to heading text.

**Optical size.** Fitting every mark into a common box does *not* work: source
icons are fit by bounding box, so a square mark (Google's G) fills 24×24 while a
wide wordmark (IBM, NASA) hits the width limit and ends up ~9 units tall — it
reads as far smaller even though both technically fill the box. The script
instead scales each mark so the **geometric mean of its bounding box** is
constant, equalizing optical *area*. Canvas width therefore varies per logo;
canvas height is what's shared.

**Color.** Monochrome, picked to stay legible on both GitHub's light (`#ffffff`)
and dark (`#0d1117`) backgrounds, which avoids needing a `<picture>` +
`prefers-color-scheme` pair for every logo.

Bounding boxes are computed analytically in [`svgpath.py`](../../scripts/svgpath.py)
so the build stays pure-stdlib; `verify_logos.py` rasterizes the output with
librsvg and confirms the measured ink matches.

## Attribution

Marks are derived from [simple-icons](https://github.com/simple-icons/simple-icons)
(CC0 1.0), pinned to v11 because later majors dropped several of these icons.

`noaa.svg` is **not** the NOAA seal. NOAA's insignia is US government imagery
whose use is restricted — it may not be used in a way that implies endorsement —
so this is a generic radar glyph standing in for the org.

All brand names and logos remain the property of their respective owners and are
used here for identification only.
